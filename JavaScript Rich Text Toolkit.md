## 🛠 Feature Breakdown

### Feature 1 — contenteditable Core
A minimal, dependency-free editable surface with caret preservation.

### Feature 2 — Custom Toolbar
Bold, italic, underline, headings, lists, quotes, code, links, colors — all customizable.

### Feature 3 — Markdown Shortcuts
Type `# ` for a heading, `- ` for a list, `> ` for a quote, `` ` `` for inline code.

### Feature 4 — Sanitized HTML
DOMPurify integration to prevent XSS in pasted or rendered content.

### Feature 5 — Image Uploads
Drag & drop, paste, and file picker with base64 or server upload.

### Feature 6 — Plugin API
Register commands, keyboard shortcuts, and custom nodes.

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Caret jumps** | Use `Range` API carefully |
| **Paste broken** | Sanitize clipboard HTML |
| **Toolbar not focusing** | Prevent default on mousedown |
| **React re-renders** | Memoize the editor |
| **SSR hydration errors** | Load editor client-side |
| **Mobile issues** | Use `beforeinput` events |
